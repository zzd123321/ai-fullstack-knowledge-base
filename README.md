# AI 全栈知识库

本仓库用于整理全栈开发相关课程的课件、示例代码、练习和数据文件。

课程来自渡一：https://app.duyiedu.com/toc-detail?productId=54a002b2-1227-4207-9aed-e75be9cdb590

会在每门课程学习时同时向chatgpt提问学习，补充相关的学习笔记。

各课程项目均作为普通目录直接保存在本仓库中，不再使用 Git 子模块。新增或修改课程资料后，在本仓库统一提交即可。
