# Neo4j

## 1. 安装 Desktop，创建本地实例

1. 下载 **Neo4j Desktop**。[官方下载](https://neo4j.com/deployment-center/)
2. 首次打开点 **Get started**，创建本地实例，命名为 `lesson-46`，保留默认版本，为用户 `neo4j` 设置密码。
3. 在实例卡片点 ▶ 启动，运行后选择 **Connect → Query**，确认顶部数据库为 `neo4j`。下面的 Cypher 代码每次粘贴一段，点击运行。

## 2. 写入三部电影和相关人物

在 **Query** 中运行。角色名直接写在出演关系里，导演、编剧和配乐分别用不同的关系类型表示。

```cypher
MERGE (inception:Movie {title: '盗梦空间'})
MERGE (interstellar:Movie {title: '星际穿越'})
MERGE (oppenheimer:Movie {title: '奥本海默'})

MERGE (nolan:Person {name: '克里斯托弗·诺兰'})
MERGE (jonathan:Person {name: '乔纳森·诺兰'})
MERGE (zimmer:Person {name: '汉斯·季默'})
MERGE (goransson:Person {name: '路德维希·戈兰松'})
MERGE (dicaprio:Person {name: '莱昂纳多·迪卡普里奥'})
MERGE (levitt:Person {name: '约瑟夫·高登-莱维特'})
MERGE (murphy:Person {name: '希里安·墨菲'})
MERGE (mcconaughey:Person {name: '马修·麦康纳'})
MERGE (hathaway:Person {name: '安妮·海瑟薇'})
MERGE (chastain:Person {name: '杰西卡·查斯坦'})
MERGE (blunt:Person {name: '艾米莉·布朗特'})
MERGE (damon:Person {name: '马特·达蒙'})

MERGE (nolan)-[:DIRECTED]->(inception)
MERGE (nolan)-[:DIRECTED]->(interstellar)
MERGE (nolan)-[:DIRECTED]->(oppenheimer)
MERGE (nolan)-[:WROTE]->(inception)
MERGE (nolan)-[:WROTE]->(interstellar)
MERGE (nolan)-[:WROTE]->(oppenheimer)
MERGE (jonathan)-[:WROTE]->(interstellar)
MERGE (zimmer)-[:COMPOSED_FOR]->(inception)
MERGE (zimmer)-[:COMPOSED_FOR]->(interstellar)
MERGE (goransson)-[:COMPOSED_FOR]->(oppenheimer)

MERGE (dicaprio)-[:ACTED_IN {role: '柯布'}]->(inception)
MERGE (levitt)-[:ACTED_IN {role: '亚瑟'}]->(inception)
MERGE (murphy)-[:ACTED_IN {role: '费舍尔'}]->(inception)
MERGE (mcconaughey)-[:ACTED_IN {role: '库珀'}]->(interstellar)
MERGE (hathaway)-[:ACTED_IN {role: '阿米莉亚·布兰德'}]->(interstellar)
MERGE (chastain)-[:ACTED_IN {role: '成年墨菲'}]->(interstellar)
MERGE (murphy)-[:ACTED_IN {role: '罗伯特·奥本海默'}]->(oppenheimer)
MERGE (blunt)-[:ACTED_IN {role: '凯蒂'}]->(oppenheimer)
MERGE (damon)-[:ACTED_IN {role: '莱斯利·格罗夫斯'}]->(oppenheimer)
```

## 3. 从角色查到另一部电影

```cypher
MATCH (first:Movie {title: '盗梦空间'})<-[firstRole:ACTED_IN {role: '费舍尔'}]-(actor:Person)
MATCH (actor)-[r:ACTED_IN]->(other:Movie)
WHERE other <> first
RETURN actor.name AS 演员, other.title AS 电影, r.role AS 角色
```

第一行从电影和角色找到演员，第二行沿同一演员的出演关系查电影，第三行排除起点《盗梦空间》。切到表格视图，应看到一行结果：

| 演员 | 电影 | 角色 |
| --- | --- | --- |
| 希里安·墨菲 | 奥本海默 | 罗伯特·奥本海默 |

把上面查询的最后一行换成下面这句，再运行并切到图形视图，就能从全图中筛出 **3 个节点、2 条关系**。

```cypher
RETURN first, firstRole, actor, r, other
```

**用 Bloom 看同一条路径。** 在实例卡片选择 **Connect → Bloom**，使用默认视图。搜索 `Person`，选中该类别并回车。右键「希里安·墨菲」，选择 **Expand** 展开两部电影，再点一条出演关系查看它的 `role` 属性。Desktop 的本地实例可以免费使用内置 Bloom。[Bloom 操作说明](https://neo4j.com/docs/desktop/current/explore/)
