# 推理引擎升级与旧版适配器销售沟通通知

ISSUE-017：引擎 3.2.1＋L23 1.0 的升级风险尚未关闭。

> 资料快照：2026-08-20；整理日期：2026-11-04。状态与结论仅适用于所引证据的时间、版本和范围。

## 提取摘要

- 研发在 CFG-A200-4＋工务通 2.3＋L23 1.0＋引擎 3.2.1 复现鉴权读取失败，错误 GW-AUTH-17，问题编号 ISSUE-017。
- [IMG-009 · 旧版适配器故障界面](IMG-009.md) 补充实验室记录 LAB-0816-017、时间 2026-08-16 10:24；不是客户现场故障凭证。
- 使用或计划使用 L23 1.0 的项目暂停自动升级 3.2.1，核对实际版本；3.2.0 仅按原验证范围保留。
- A200 四卡＋工务通 3.0＋S30 2.0 复测未复现该错误，不代表所有硬件配置完成升级认证。
- L23 1.1 在研发计划中，未完成与 3.2.1 验证，无可承诺发布日期；已升级且报错时由支持评估恢复，不授权销售自行改客户环境。
- 需联合商机、方案和报价识别组件与版本，不能仅按 A200 系列筛选客户。
