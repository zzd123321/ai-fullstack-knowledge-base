# 修订不合格分镜

**核型目标**

对不合格的分镜做修订。



**工作流**

> 见 PPT



## schema

`revision_record.py`

```py
from pydantic import BaseModel, ConfigDict, Field

class RevisionRecord(BaseModel):
    model_config = ConfigDict(extra="forbid")
    version: int = Field(ge=0)
    fingerprint: str = Field(min_length=16, max_length=16)
    source_codes: list[str]
    target_shot_ids: list[str]
```

- version：版本号
- fingerprint：这一整版分镜的 **<u>指纹</u>**，通过计算 hash 得到。
- source_codes：因为哪类问题而修订，例如 `["plot_gap"]`
- target_shot_ids：这一版实际允许改的镜头 ID，来自报告的 `affected_shot_ids`

## state

```py
revision_count: NotRequired[int]
max_revisions: NotRequired[int]
revision_history: NotRequired[list[RevisionRecord]]
stop_reason: NotRequired[str | None]
```

- `revision_count`：记录修订的次数
- `max_revisions`：本轮最多自动修订几次
- `revision_history`：版本列表
- `stop_reason`：停止原因

## prompt

`revision_prompt.py`

```py
REVISION_PROMPT = """你是漫剧分镜修订者。只根据质量报告修改当前完整分镜，不改需求、故事大纲、角色库或场景库。
输入会明确 allowed_shot_ids；只返回这些目标镜头的完整 StoryBoard 对象，放在 storyboard_list 中，不返回非目标镜头。
必须恰好覆盖全部 allowed_shot_ids，不得遗漏、重复、增加或改写 ID；保持对应 order 不变。
Python 会合并原稿；目标镜头的时长合计必须保持不变，以保持全片总时长。
当 allowed_shot_ids 包含全部镜头时，才允许整稿修订；不能自行扩大范围。
采用解决问题所需的最小改动，优先处理 error；warning 仅在不引入新矛盾且不扩大范围时顺带改善。保留目标镜头中与问题无关的原有内容，不做全段风格重写。
逐条核对 description 与 suggestion，在原有设定下落实修复；建议是修复线索，不可机械照抄与原稿冲突的建议。
不引入无关道具、额外角色动作、新奇幻规则或新的情节分支来解释旧问题；补充必要过渡应使用已有角色、道具与设定。
核对道具来源、数量、持有者与状态，以及入口、人物的空间关系；目标镜头必须与未修改的前后镜头衔接。
同步调整目标镜头中确有必要的 action、dialogue、首尾帧和 video_prompt，避免只补一个字段却与其他字段冲突；人物运动与摄影机运动分开描述。
若问题依赖不可修改的上游设定或非目标镜头，不擅自扩大修订范围或捏造规则；保留无法安全修改的内容，留给后续评价与人工处理。
只引用已有角色和场景 ID。不要添加解释文本，只返回符合 StoryBoardList Schema 的结构化对象，镜头放在 storyboard_list 中。"""

```
