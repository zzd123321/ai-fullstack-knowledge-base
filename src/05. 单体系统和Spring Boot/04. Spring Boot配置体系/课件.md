# Spring Boot 配置体系

## 课程目标

- 掌握 `application.properties` 和 `application.yml` 两种配置文件的格式
- 掌握使用 `@Value` 和 `@ConfigurationProperties` 读取配置
- 理解多环境配置（Profile）的切换方法
- 了解 Spring Boot 配置加载的优先级顺序
- 能够在项目中配置多环境参数



## 配置文件格式

Spring Boot 支持两种格式的配置文件，都放在 `src/main/resources/` 目录下：

| 格式       | 文件名                   | 特点                                 |
| ---------- | ------------------------ | ------------------------------------ |
| Properties | `application.properties` | 键值对格式，简洁                     |
| YAML       | `application.yml`        | 树形结构，层次清晰，支持复杂数据类型 |

### Properties 格式

```properties
# application.properties
# 服务器配置
server.port=8080
server.servlet.context-path=/api

# 应用配置
app.name=图书管理系统
app.version=1.0.0

# 数据源配置（示例）
spring.datasource.url=jdbc:h2:mem:testdb
spring.datasource.username=sa
spring.datasource.password=
```

### YAML 格式（推荐）

YAML（YAML Ain‘t Markup Language）使用**缩进**表示层级关系，结构更清晰：

```yaml
# application.yml
server:
  port: 8080
  servlet:
    context-path: /api

app:
  name: 图书管理系统
  version: 1.0.0

spring:
  datasource:
    url: jdbc:h2:mem:testdb
    username: sa
    password:
```

**YAML 与 Properties 对比：**

| 对比         | Properties         | YAML              |
| ------------ | ------------------ | ----------------- |
| 可读性       | 一般（重复前缀多） | 好（树形结构）    |
| 复杂数据类型 | 不支持             | 支持（List、Map） |
| 注释         | `#`                | `#`               |
| 推荐度       | ⭐⭐⭐                | ⭐⭐⭐⭐⭐             |

> [!NOTE]
> 本课程后续统一使用 `application.yml` 格式。



### YAML 中的复杂数据类型

**List（列表）：**

```yaml
app:
  features:
    - 图书管理
    - 用户管理
    - 统计分析
```

**Map（键值对）：**

```yaml
app:
  contact:
    email: admin@example.com
    phone: 010-12345678
```

**嵌套对象：**

```yaml
app:
  info:
    name: 图书管理系统
    version: 1.0.0
    author: 技术团队
```



## 读取配置的两种方式

### 方式一：@Value 注解

`@Value` 用于将配置文件中的单个值注入到字段中。

**配置文件（application.yml）：**

```yaml
app:
  name: 图书管理系统
  version: 1.0.0
  welcome-message: 欢迎使用图书管理系统！
```

**代码中使用：**

```java
package com.example.bookmanager.controller;

import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ConfigController {

    @Value("${app.name}")
    private String appName;

    @Value("${app.version}")
    private String appVersion;

    @Value("${app.welcome-message:默认欢迎语}")  // 冒号后面是默认值
    private String welcomeMessage;

    @GetMapping("/info")
    public String getAppInfo() {
        return String.format("应用: %s, 版本: %s", appName, appVersion);
    }

    @GetMapping("/welcome")
    public String getWelcome() {
        return welcomeMessage;
    }
}
```

**访问 `/info` 返回：**

```text
应用: 图书管理系统, 版本: 1.0.0
```

> [!NOTE]
> `@Value` 中的 `${}` 是占位符语法，`${app.welcome-message:默认欢迎语}` 表示如果配置中没有 `app.welcome-message`，则使用默认值“默认欢迎语”。



### 方式二：@ConfigurationProperties（推荐）

当配置项较多时，使用 `@ConfigurationProperties` 可以将一组配置绑定到一个 Java 对象中，更加整洁、类型安全。

**配置文件（application.yml）：**

```yaml
app:
  name: 图书管理系统
  version: 1.0.0
  author: 技术团队
  features:
    - 图书管理
    - 用户管理
    - 统计分析
  contact:
    email: admin@example.com
    phone: 010-12345678
```

**配置类：**

```java
package com.example.bookmanager.config;

import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

import java.util.List;
import java.util.Map;

@Component
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private String name;
    private String version;
    private String author;
    private List<String> features;
    private Map<String, String> contact;

    // Getter 和 Setter（必须要有）
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getVersion() { return version; }
    public void setVersion(String version) { this.version = version; }
    public String getAuthor() { return author; }
    public void setAuthor(String author) { this.author = author; }
    public List<String> getFeatures() { return features; }
    public void setFeatures(List<String> features) { this.features = features; }
    public Map<String, String> getContact() { return contact; }
    public void setContact(Map<String, String> contact) { this.contact = contact; }
}
```

**使用配置类：**

```java
@RestController
@RequestMapping("/api/config")
public class ConfigController {

    @Autowired
    private AppProperties appProperties;

    @GetMapping
    public Map<String, Object> getAppConfig() {
        Map<String, Object> result = new HashMap<>();
        result.put("name", appProperties.getName());
        result.put("version", appProperties.getVersion());
        result.put("author", appProperties.getAuthor());
        result.put("features", appProperties.getFeatures());
        result.put("contact", appProperties.getContact());
        return result;
    }
}
```

**访问 `/api/config` 返回：**

```json
{
    "name": "图书管理系统",
    "version": "1.0.0",
    "author": "技术团队",
    "features": ["图书管理", "用户管理", "统计分析"],
    "contact": {
        "email": "admin@example.com",
        "phone": "010-12345678"
    }
}
```



### **@Value vs @ConfigurationProperties：**

| 对比       | @Value           | @ConfigurationProperties   |
| ---------- | ---------------- | -------------------------- |
| 适用场景   | 单个配置值       | 一组相关配置               |
| 类型安全   | 弱（字符串转换） | 强（自动类型转换）         |
| 复杂类型   | 不支持 List/Map  | 支持 List/Map              |
| 代码整洁度 | 字段分散         | 集中管理                   |
| IDE 支持   | 无代码提示       | 有代码提示（需添加处理器） |

> [!NOTE]
>
> 要在使用 `@ConfigurationProperties` 时实现代码提示，核心是为项目添加 **`spring-boot-configuration-processor`** 依赖。
>
> > ```xml
> > <dependency>
> >  		<groupId>org.springframework.boot</groupId>
> >  		<artifactId>spring-boot-configuration-processor</artifactId>
> >  		<optional>true</optional>
> > </dependency>
> > ```
>
> 这个注解处理器会在编译时，为你的自定义配置类生成一个元数据（metadata）文件。IDE（如 IntelliJ IDEA）正是通过读取这个文件，才知道你的自定义属性，从而实现自动补全、跳转和文档提示。

同时，需要确保 IDE 注解处理已开启，操作方法如下：

- 打开 `Settings` (或 `Preferences`)。
- 导航到 `Build, Execution, Deployment` -> `Compiler` -> `Annotation Processors`。
- 确保 **`Enable annotation processing`** 选项已被勾选

然后**重新构建项目**：添加依赖并确认 IDE 设置无误后，**必须执行一次完整的项目重建（Rebuild）**。这会触发注解处理器运行，并在 `target/classes/META-INF/` 目录下生成 `spring-configuration-metadata.json` 文件



## 多环境配置（Profile）

### 场景需求：多环境配置

在实际开发中，我们通常需要在不同环境中使用不同的配置：

| 环境                 | 特点                            |
| -------------------- | ------------------------------- |
| **开发环境（dev）**  | 本地数据库、DEBUG 日志、热部署  |
| **测试环境（test）** | 测试数据库、INFO 日志           |
| **生产环境（prod）** | 生产数据库、WARN 日志、性能优化 |

### 解决方案：创建多环境配置文件

Spring Boot 支持通过 `application-{profile}.yml` 的命名规则来区分环境：

```
src/main/resources/
├── application.yml              # 通用配置
├── application-dev.yml          # 开发环境
├── application-test.yml         # 测试环境
└── application-prod.yml         # 生产环境
```

**application.yml（通用配置）：**

```yaml
app:
  name: 图书管理系统
  version: 1.0.0

spring:
  profiles:
    active: dev  # 默认激活 dev 环境
```

**application-dev.yml（开发环境）：**

```yaml
server:
  port: 8080

logging:
  level:
    com.example.bookmanager: DEBUG
    
app:
  author: 开发团队
  description: 开发环境 - 使用内存存储
```

**application-prod.yml（生产环境）：**

```yaml
server:
  port: 9090

logging:
  level:
    com.example.bookmanager: WARN
    
app:
  author: 运维团队
  description: 生产环境 - 使用数据库存储
```



### 激活 Profile 的方式

#### 方式一：在 application.yml 中指定（默认）

```yaml
spring:
  profiles:
    active: dev
```

#### 方式二：命令行参数（最高优先级）

```
java -jar book-manager.jar --spring.profiles.active=prod
```

#### 方式三：IDE 中配置

在 IntelliJ IDEA 中：

1. 点击 **Run → Edit Configurations**

2. 在 **Environment → VM options** 中添加：

   ```
   -Dspring.profiles.active=prod
   ```
   
   或在 **Program arguments** 中添加：

   ```
   --spring.profiles.active=prod
   ```


#### 方式四：环境变量

```
export SPRING_PROFILES_ACTIVE=prod
java -jar book-manager.jar
```

### 验证当前激活的 Profile

```java
@RestController
public class ProfileController {

    @Value("${spring.profiles.active:default}")
    private String activeProfile;

    @GetMapping("/profile")
    public String getProfile() {
        return "当前激活的 Profile: " + activeProfile;
    }
}
```



## 配置加载优先级

Spring Boot 支持多种配置来源，它们之间存在**优先级顺序**（后面的优先级更高）：

```
优先级从低到高：
1. 默认配置（Spring Boot 内置默认值）
2. application.yml / application.properties（项目内）
3. application-{profile}.yml（环境专用配置）
4. 外部配置文件（jar 包同目录的 /config 子目录）
5. 外部配置文件（jar 包同目录）
6. 命令行参数（--server.port=9090）
7. 环境变量（SPRING_APPLICATION_JSON）
8. 系统属性（-Dserver.port=9090）
```



### 优先级演示

**场景：** 同时存在以下配置来源：

1. `application.yml`：`server.port: 8080`
2. `application-dev.yml`：`server.port: 8081`（激活 dev）
3. 命令行参数：`--server.port=9090`

**最终生效的端口是 9090**（命令行参数优先级最高）。



### 配置覆盖规则

```mermaid
flowchart LR
    Default[默认配置] --> App[application.yml]
    App --> Profile[application-dev.yml]
    Profile --> Cmd[命令行参数]
    Cmd --> Env[环境变量]
    Env --> System[-D系统属性]

    System --> Result[最终配置]
```

> [!NOTE]
> 优先级高的配置会**覆盖**优先级低的配置，而不是合并。



## 实战：为图书管理系统添加多环境配置

### 创建配置文件

在 `src/main/resources/` 下创建以下文件：

**application.yml（通用）：**

```yaml
spring:
  profiles:
    active: dev

app:
  name: 图书管理系统
  version: 1.0.0
```

**application-dev.yml（开发环境）：**

```yaml
server:
  port: 8080

logging:
  level:
    com.example.bookmanager: DEBUG

app:
  author: 开发团队
  description: 开发环境 - 使用内存存储
  welcome-message: 欢迎来到开发环境
```

**application-prod.yml（生产环境）：**

```yaml
server:
  port: 80

logging:
  level:
    com.example.bookmanager: WARN

app:
  author: 运维团队
  description: 生产环境 - 使用数据库存储
  welcome-message: 欢迎访问图书管理系统
```

### 创建配置类

```java
package com.example.bookmanager.config;

import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

@Component
@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private String name;
    private String version;
    private String author;
    private String description;
    private String welcomeMessage;

    // Getter 和 Setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public String getVersion() { return version; }
    public void setVersion(String version) { this.version = version; }
    public String getAuthor() { return author; }
    public void setAuthor(String author) { this.author = author; }
    public String getDescription() { return description; }
    public void setDescription(String description) { this.description = description; }
    public String getWelcomeMessage() { return welcomeMessage; }
    public void setWelcomeMessage(String welcomeMessage) { this.welcomeMessage = welcomeMessage; }
}
```

### 验证配置

```java
package com.example.bookmanager.controller;

import com.example.bookmanager.config.AppProperties;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.HashMap;
import java.util.Map;

@RestController
@RequestMapping("/api/config")
public class ConfigController {

    @Autowired
    private AppProperties appProperties;

    @Value("${spring.profiles.active:default}")
    private String activeProfile;

    @GetMapping
    public Map<String, Object> getConfig() {
        Map<String, Object> result = new HashMap<>();
        result.put("activeProfile", activeProfile);
        result.put("appName", appProperties.getName());
        result.put("appVersion", appProperties.getVersion());
        result.put("appAuthor", appProperties.getAuthor());
        result.put("appDescription", appProperties.getDescription());
        result.put("welcomeMessage", appProperties.getWelcomeMessage());
        return result;
    }
}
```

### 测试

**启动时激活 dev 环境：**

```
java -jar book-manager.jar --spring.profiles.active=dev
```

访问 `/api/config`，应返回 dev 环境的配置值。

**启动时激活 prod 环境：**

```
java -jar book-manager.jar --spring.profiles.active=prod
```

访问 `/api/config`，应返回 prod 环境的配置值（如端口 80、WARN 日志等）。



## 小结

本节课我们学习了：

1. **两种配置文件格式**：Properties 和 YAML，推荐使用 YAML。
2. **读取配置的两种方式**：
   - `@Value`：适合单个配置值
   - `@ConfigurationProperties`：适合一组相关配置（推荐）
3. **多环境配置（Profile）**：
   - 使用 `application-{profile}.yml` 区分环境
   - 通过 `spring.profiles.active` 激活
   - 支持多种激活方式（配置文件、命令行、环境变量）
4. **配置加载优先级**：命令行参数 > 环境变量 > 系统属性 > Profile 配置 > 默认配置
5. **实战应用**：为图书管理系统添加了多环境配置
