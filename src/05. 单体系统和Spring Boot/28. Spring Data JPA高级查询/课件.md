## 方法命名查询（Query Methods）

### 什么是方法命名查询

Spring Data JPA 能根据方法名自动生成 SQL 查询，无需编写 JPQL 或 SQL。这是最方便、最常用的查询方式。

**命名规则：** `findBy + 属性名 + 操作符`

### 常用前缀

| 前缀           | 说明                         |
| -------------- | ---------------------------- |
| `findBy...`    | 查询集合                     |
| `findOneBy...` | 查询单个对象                 |
| `existsBy...`  | 判断是否存在（返回 boolean） |
| `countBy...`   | 统计数量                     |
| `deleteBy...`  | 删除（支持批量）             |

### 支持的属性操作符

| 关键字         | 示例                          | 生成的 SQL 片段                     |
| -------------- | ----------------------------- | ----------------------------------- |
| `And`          | `findByAuthorAndCategory`     | `WHERE author = ? AND category = ?` |
| `Or`           | `findByAuthorOrCategory`      | `WHERE author = ? OR category = ?`  |
| `Between`      | `findByPriceBetween`          | `WHERE price BETWEEN ? AND ?`       |
| `LessThan`     | `findByPriceLessThan`         | `WHERE price < ?`                   |
| `GreaterThan`  | `findByPriceGreaterThan`      | `WHERE price > ?`                   |
| `Like`         | `findByTitleLike`             | `WHERE title LIKE ?`                |
| `Containing`   | `findByTitleContaining`       | `WHERE title LIKE %?%`              |
| `StartingWith` | `findByTitleStartingWith`     | `WHERE title LIKE ?%`               |
| `EndingWith`   | `findByTitleEndingWith`       | `WHERE title LIKE %?`               |
| `In`           | `findByCategoryIn`            | `WHERE category IN (?)`             |
| `IsNull`       | `findByCategoryIsNull`        | `WHERE category IS NULL`            |
| `IsNotNull`    | `findByCategoryIsNotNull`     | `WHERE category IS NOT NULL`        |
| `OrderBy`      | `findByAuthorOrderByPriceAsc` | `ORDER BY price ASC`                |

### 在图书管理系统中使用方法命名查询

在 `BookRepository` 中添加以下方法：

```java
@Repository
public interface BookRepository extends JpaRepository<Book, Long> {

    // ---------- 基本查询 ----------
    List<Book> findByAuthor(String author);

    List<Book> findByCategory(String category);

    List<Book> findByTitleContaining(String keyword);

    List<Book> findByAuthorAndCategory(String author, String category);

    List<Book> findByAuthorOrCategory(String author, String category);

    // ---------- 范围查询 ----------
    List<Book> findByPriceBetween(Double min, Double max);

    List<Book> findByPriceLessThan(Double max);

    List<Book> findByPriceGreaterThan(Double min);

    // ---------- 排序查询 ----------
    List<Book> findByAuthorOrderByPriceAsc(String author);

    List<Book> findByCategoryOrderByPriceDesc(String category);

    // ---------- 集合查询 ----------
    List<Book> findByCategoryIn(List<String> categories);

    // ---------- 存在性查询 ----------
    boolean existsByAuthor(String author);

    long countByCategory(String category);

    // ---------- 删除查询 ----------
    long deleteByAuthor(String author);  // 删除指定作者的所有图书
}
```

> [!NOTE]
> `deleteBy...` 方法需要添加 `@Modifying` 和 `@Transactional` 注解（详见后续内容），否则会抛出异常。

### 方法命名查询的原理

Spring Data JPA 在启动时会解析方法名，生成对应的 JPQL 查询。例如：

| 方法                                         | 自动生成的 JPQL                                              |
| -------------------------------------------- | ------------------------------------------------------------ |
| `findByAuthor(String author)`                | `SELECT b FROM Book b WHERE b.author = ?1`                   |
| `findByPriceBetween(Double min, Double max)` | `SELECT b FROM Book b WHERE b.price BETWEEN ?1 AND ?2`       |
| `findByTitleContaining(String keyword)`      | `SELECT b FROM Book b WHERE b.title LIKE CONCAT('%', ?1, '%')` |

> [!NOTE]
> 方法命名查询虽然方便，但方法名可能变得很长，且不支持复杂查询（如多表关联、子查询等）。对于复杂场景，可以使用 `@Query` 注解。



## @Query 注解

### 什么是 @Query

`@Query` 注解允许开发者直接在 Repository 方法上定义 JPQL 或原生 SQL 查询语句，提供了最大的灵活性。

### JPQL 查询

**JPQL（Java Persistence Query Language）** 是 JPA 定义的面向对象的查询语言，操作的是**实体对象**而非数据库表。

```java
@Repository
public interface BookRepository extends JpaRepository<Book, Long> {

    // ---------- 基本 JPQL ----------
    @Query("SELECT b FROM Book b WHERE b.author = :author")
    List<Book> findBooksByAuthor(@Param("author") String author);

    @Query("SELECT b FROM Book b WHERE b.price BETWEEN :min AND :max")
    List<Book> findBooksByPriceRange(@Param("min") Double min, @Param("max") Double max);

    // ---------- 多条件 JPQL ----------
    @Query("SELECT b FROM Book b WHERE " +
           "(:author IS NULL OR b.author LIKE %:author%) AND " +
           "(:category IS NULL OR b.category = :category) AND " +
           "(:minPrice IS NULL OR b.price >= :minPrice) AND " +
           "(:maxPrice IS NULL OR b.price <= :maxPrice)")
    List<Book> searchBooks(@Param("author") String author,
                           @Param("category") String category,
                           @Param("minPrice") Double minPrice,
                           @Param("maxPrice") Double maxPrice);
}
```

> [!NOTE]
> `@Param` 注解用于绑定方法参数到 JPQL 中的命名参数（`:author`）。如果参数名与 JPQL 中的命名参数一致，且编译时保留参数名（`-parameters`），可省略 `@Param`。

### 原生 SQL 查询

当 JPQL 无法满足需求（如使用数据库特有函数、复杂关联查询）时，可以使用原生 SQL：

```java
@Repository
public interface BookRepository extends JpaRepository<Book, Long> {

    // 原生 SQL 查询
    @Query(value = "SELECT * FROM book WHERE title ILIKE %:keyword%", nativeQuery = true)
    List<Book> findByTitleKeywordNative(@Param("keyword") String keyword);

    // 使用 PostgreSQL 特定函数
    @Query(value = "SELECT * FROM book WHERE EXTRACT(YEAR FROM created_at) = :year", nativeQuery = true)
    List<Book> findBooksByYear(@Param("year") int year);
}
```

> [!CAUTION]
> 原生 SQL 会绕过 JPA 的自动映射，查询结果映射可能存在风险。同时，原生 SQL 与数据库绑定，切换数据库时需要修改 SQL。

### JPQL vs 原生 SQL

| 对比              | JPQL                   | 原生 SQL                     |
| ----------------- | ---------------------- | ---------------------------- |
| **操作对象**      | 实体对象               | 数据库表                     |
| **与数据库耦合**  | 低                     | 高（依赖特定语法）           |
| **支持 JPA 特性** | 支持（懒加载、缓存等） | 部分支持                     |
| **性能**          | 略低（需转换为 SQL）   | 最高（直接执行）             |
| **推荐场景**      | 大多数场景             | 复杂查询、使用数据库特有功能 |

> [!NOTE]
> 推荐优先使用 JPQL，仅在需要数据库特定功能或性能优化时使用原生 SQL。

### 查询结果封装

当查询只返回部分字段时，可以自定义 DTO（数据传输对象）接收结果：

```java
// DTO 定义
public class BookSummary {
    private Long id;
    private String title;
    private String author;
    private Double price;

    // 构造方法（必须与 @Query 结果匹配）
    public BookSummary(Long id, String title, String author, Double price) {
        this.id = id;
        this.title = title;
        this.author = author;
        this.price = price;
    }
    // Getter...
}

@Repository
public interface BookRepository extends JpaRepository<Book, Long> {
    @Query("SELECT new com.example.bookmanager.repository.dto.BookSummary(b.id, b.title, b.author, b.price) FROM Book b WHERE b.price > :minPrice")
    List<BookSummary> findBookSummaries(@Param("minPrice") Double minPrice);
}
```



## 分页与排序

### 使用 Pageable 进行分页

**Pageable** 是 Spring Data 提供的分页和排序抽象，支持动态分页。

```java
@Repository
public interface BookRepository extends JpaRepository<Book, Long> {

    // ---------- 方法命名查询 + 分页 ----------
    Page<Book> findByCategory(String category, Pageable pageable);

    // ---------- @Query + 分页 ----------
    @Query("SELECT b FROM Book b WHERE b.price > :minPrice")
    Page<Book> findExpensiveBooks(@Param("minPrice") Double minPrice, Pageable pageable);
}
```

### 在 Service 中使用分页

```java
@Service
public class BookService {

    @Autowired
    private BookRepository bookRepository;

    public Page<Book> getBooksByCategory(String category, int page, int size) {
        Pageable pageable = PageRequest.of(page - 1, size); // page 从 0 开始
        return bookRepository.findByCategory(category, pageable);
    }

    public Page<Book> getBooksWithSort(int page, int size, String sortBy, String direction) {
        Sort sort = Sort.by(Sort.Direction.fromString(direction), sortBy);
        Pageable pageable = PageRequest.of(page - 1, size, sort);
        return bookRepository.findAll(pageable);
    }
}
```

### 分页结果封装（Page 对象）

`Page<T>` 提供了丰富的信息：

| 方法                 | 说明                  |
| -------------------- | --------------------- |
| `getContent()`       | 当前页数据列表        |
| `getTotalElements()` | 总记录数              |
| `getTotalPages()`    | 总页数                |
| `getNumber()`        | 当前页码（从 0 开始） |
| `getSize()`          | 每页大小              |
| `getSort()`          | 排序信息              |
| `hasNext()`          | 是否有下一页          |
| `hasPrevious()`      | 是否有上一页          |

### 使用 Sort 进行排序

```java
public List<Book> getBooksSortedByPriceDesc() {
    Sort sort = Sort.by(Sort.Direction.DESC, "price");
    return bookRepository.findAll(sort);
}

public List<Book> getBooksSortedByMultipleFields() {
    Sort sort = Sort.by(Sort.Order.desc("price"), Sort.Order.asc("title"));
    return bookRepository.findAll(sort);
}
```



## @Modifying 更新与删除操作

### 使用 @Modifying 进行更新

`@Query` 默认用于查询（SELECT）。执行 UPDATE 或 DELETE 操作时，需要添加 `@Modifying` 注解。

```java
@Repository
public interface BookRepository extends JpaRepository<Book, Long> {

    // 批量更新价格
    @Modifying
    @Query("UPDATE Book b SET b.price = b.price * :multiplier WHERE b.category = :category")
    int updatePriceByCategory(@Param("multiplier") Double multiplier,
                             @Param("category") String category);

    // 批量删除
    @Modifying
    @Query("DELETE FROM Book b WHERE b.author = :author")
    int deleteByAuthor(@Param("author") String author);

    // 更新单条（使用 @Modifying + 原生 SQL）
    @Modifying
    @Query(value = "UPDATE book SET stock = stock - :quantity WHERE id = :id", nativeQuery = true)
    int decreaseStock(@Param("id") Long id, @Param("quantity") int quantity);
}
```

### @Modifying 注解的关键属性

| 属性                 | 说明                                 | 默认值  |
| -------------------- | ------------------------------------ | ------- |
| `flushAutomatically` | 在执行修改前是否自动刷新持久化上下文 | `false` |
| `clearAutomatically` | 执行后是否清除持久化上下文           | `false` |

> [!CAUTION]
> `@Modifying` 方法执行后，持久化上下文（EntityManager 中的一级缓存）可能包含过时的数据。建议设置 `clearAutomatically = true` 清除缓存。

```java
@Modifying(clearAutomatically = true)
@Query("UPDATE Book b SET b.price = :price WHERE b.id = :id")
int updatePrice(@Param("id") Long id, @Param("price") Double price);
```

### @Modifying 与事务

`@Modifying` 方法必须在事务中执行。通常在 Service 层添加 `@Transactional`，或在 Repository 方法上添加 `@Transactional`。

```java
@Service
@Transactional
public class BookService {
    @Autowired
    private BookRepository bookRepository;

    public int bulkPriceUpdate(String category, Double multiplier) {
        return bookRepository.updatePriceByCategory(multiplier, category);
    }
}
```



## 查询方式的选择策略

| 场景                         | 推荐方式                |
| ---------------------------- | ----------------------- |
| 简单单表查询                 | 方法命名查询            |
| 中等复杂查询（多条件、排序） | 方法命名查询 + Pageable |
| 复杂条件（多表关联、子查询） | @Query（JPQL）          |
| 使用数据库特有功能           | @Query（原生 SQL）      |
| 只查询部分字段               | DTO + @Query            |
| 批量更新/删除                | @Modifying + @Query     |



## 实战：图书管理系统高级查询示例

### Repository 代码

```java
@Repository
public interface BookRepository extends JpaRepository<Book, Long> {

    // ---------- 方法命名查询 ----------
    List<Book> findByAuthor(String author);

    List<Book> findByCategory(String category);

    List<Book> findByTitleContaining(String keyword);

    List<Book> findByPriceBetween(Double min, Double max);

    Page<Book> findByCategory(String category, Pageable pageable);

    // ---------- @Query JPQL ----------
    @Query("SELECT b FROM Book b WHERE b.author LIKE %:author% AND b.price BETWEEN :min AND :max")
    List<Book> searchByAuthorAndPrice(@Param("author") String author,
                                      @Param("min") Double min,
                                      @Param("max") Double max);

    @Query("SELECT b FROM Book b WHERE b.category IN :categories")
    List<Book> findByCategories(@Param("categories") List<String> categories);

    // ---------- 原生 SQL ----------
    @Query(value = "SELECT * FROM book WHERE title ILIKE %:keyword%", nativeQuery = true)
    List<Book> searchByTitleNative(@Param("keyword") String keyword);

    // ---------- 分页查询 ----------
    @Query("SELECT b FROM Book b WHERE b.price > :minPrice")
    Page<Book> findBooksAbovePrice(@Param("minPrice") Double minPrice, Pageable pageable);

    // ---------- 聚合查询 ----------
    @Query("SELECT AVG(b.price) FROM Book b")
    Double getAveragePrice();

    @Query("SELECT MAX(b.price) FROM Book b WHERE b.category = :category")
    Double getMaxPriceByCategory(@Param("category") String category);

    // ---------- 更新操作 ----------
    @Modifying(clearAutomatically = true)
    @Query("UPDATE Book b SET b.stock = b.stock + :delta WHERE b.id = :id")
    int updateStock(@Param("id") Long id, @Param("delta") int delta);

    @Modifying(clearAutomatically = true)
    @Query("DELETE FROM Book b WHERE b.category = :category")
    int deleteByCategory(@Param("category") String category);
}
```

### Service 层示例

```java

    }
```

## 注意事项

### 1. 方法命名查询的限制

- 方法名不能太长，否则难以维护
- 不支持多表关联（可用 `@Query`）

### 2. @Query 中的参数绑定

- 使用 `:` 加参数名（如 `:author`）
- 使用 `@Param` 绑定方法参数
- 支持 SpEL 表达式（如 `:#{#param}`）

### 3. @Modifying 的副作用

- 修改操作不会自动刷新持久化上下文，可能导致查询结果过时
- 建议设置 `clearAutomatically = true` 清除缓存
- 必须配合 `@Transactional` 使用

### 4. 分页参数

- `PageRequest.of(page, size)` 中 `page` 从 `0` 开始
- 用户传入的页码通常从 `1` 开始，需减 1 转换

### 5. 性能考虑

- 大结果集查询建议使用分页
- `@Query` 复杂查询要注意 SQL 性能
- 原生 SQL 可以使用数据库特有的性能优化语法



## 小结

本节课我们学习了：

1. **方法命名查询**：通过 `findBy` + 属性名 + 操作符自动生成 SQL，简单易用。
2. **@Query 注解**：支持 JPQL 和原生 SQL，提供最大灵活性。
3. **分页与排序**：`Pageable` 和 `Sort` 实现动态分页和排序查询。
4. **@Modifying**：执行更新和删除操作，注意清理持久化上下文。
5. **查询策略**：根据场景选择合适的方式，保持代码可读性。
