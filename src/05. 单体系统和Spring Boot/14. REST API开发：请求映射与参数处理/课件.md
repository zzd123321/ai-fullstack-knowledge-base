## 请求映射注解

### @RequestMapping

`@RequestMapping` 是 Spring WebMVC 中最基础的请求映射注解，用于将 HTTP 请求映射到 Controller 方法。可以通过 method 属性指定 HTTP 方法。

```java
@RestController
@RequestMapping("/api/books")
public class BookController {

    // 处理 GET 请求
    @RequestMapping(method = RequestMethod.GET)
    public List<Book> getAllBooks() { ... }

    // 处理 POST 请求
    @RequestMapping(method = RequestMethod.POST)
    public Book createBook(@RequestBody Book book) { ... }
}
```

### 组合注解

Spring 4.3 引入了更简洁的组合注解，每个注解对应一种 HTTP 方法：

| 注解             | 等价于                                           | 说明        |
| ---------------- | ------------------------------------------------ | ----------- |
| `@GetMapping`    | `@RequestMapping(method = RequestMethod.GET)`    | GET 请求    |
| `@PostMapping`   | `@RequestMapping(method = RequestMethod.POST)`   | POST 请求   |
| `@PutMapping`    | `@RequestMapping(method = RequestMethod.PUT)`    | PUT 请求    |
| `@DeleteMapping` | `@RequestMapping(method = RequestMethod.DELETE)` | DELETE 请求 |
| `@PatchMapping`  | `@RequestMapping(method = RequestMethod.PATCH)`  | PATCH 请求  |

```java
@RestController
@RequestMapping("/api/books")
public class BookController {

    @GetMapping
    public List<Book> getAllBooks() { ... }

    @GetMapping("/{id}")
    public Book getBook(@PathVariable Long id) { ... }

    @PostMapping
    public Book createBook(@RequestBody Book book) { ... }

    @PutMapping("/{id}")
    public Book updateBook(@PathVariable Long id, @RequestBody Book book) { ... }

    @DeleteMapping("/{id}")
    public void deleteBook(@PathVariable Long id) { ... }
}
```

### 路径映射的匹配规则

| 规则       | 示例                                | 匹配路径                                 |
| ---------- | ----------------------------------- | ---------------------------------------- |
| 精确匹配   | `@GetMapping("/books")`             | `/books`                                 |
| 路径参数   | `@GetMapping("/books/{id}")`        | `/books/1`、`/books/abc`                 |
| 通配符     | `@GetMapping("/books/*")`           | `/books/1`、`/books/abc`（不匹配子路径） |
| 多个通配符 | `@GetMapping("/books/**")`          | `/books/1`、`/books/1/details`           |
| 正则匹配   | `@GetMapping("/books/{id:[0-9]+}")` | `/books/123`（不匹配 `/books/abc`）      |

> [!NOTE]
> 路径匹配时，精确匹配优先级最高，通配符优先级最低。



## 参数绑定

Spring WebMVC 提供了丰富的注解来绑定 HTTP 请求中的参数到 Controller 方法参数。

### @PathVariable —— 路径参数

用于从 URL 路径中提取变量值。

```java
@GetMapping("/books/{id}")
public Book getBook(@PathVariable Long id) {
    // 当 URL 为 /books/1 时，id = 1
    return bookService.getBookById(id);
}
```

**指定参数名：**

```java
@GetMapping("/books/{bookId}")
public Book getBook(@PathVariable("bookId") Long id) {
    // URL 中的变量名是 bookId，方法参数名是 id
    return bookService.getBookById(id);
}
```

**多个路径参数：**

```java
@GetMapping("/books/{bookId}/reviews/{reviewId}")
public Review getReview(@PathVariable Long bookId, @PathVariable Long reviewId) {
    // URL: /books/1/reviews/5
    return reviewService.findById(bookId, reviewId);
}
```



### @RequestParam —— 查询参数

用于从 URL 查询字符串中获取参数。

```java
@GetMapping("/books")
public List<Book> getBooks(@RequestParam String author) {
    // URL: /books?author=Craig
    return bookService.getBooksByAuthor(author);
}
```

**常用属性：**

| 属性             | 说明                             |
| ---------------- | -------------------------------- |
| `value` / `name` | 参数名称（默认与方法参数名相同） |
| `required`       | 是否必须（默认 true）            |
| `defaultValue`   | 默认值（当参数缺失时使用）       |

```java
@GetMapping("/books")
public List<Book> searchBooks(
        @RequestParam(required = false) String author,
        @RequestParam(defaultValue = "0") Double minPrice,
        @RequestParam(defaultValue = "1000") Double maxPrice) {
    // URL: /books?author=Craig&minPrice=50&maxPrice=100
    return bookService.search(author, minPrice, maxPrice);
}
```

**接收数组/集合：**

```java
@GetMapping("/books")
public List<Book> getBooks(@RequestParam List<Long> ids) {
    // URL: /books?ids=1&ids=2&ids=3
    return bookService.getBooksByIds(ids);
}
```



### @RequestBody —— 请求体

用于将 HTTP 请求体中的 JSON/XML 数据绑定到 Java 对象。

```java
@PostMapping("/books")
public Book createBook(@RequestBody Book book) {
    // 请求体中的 JSON 自动转换为 Book 对象
    return bookService.createBook(book);
}
```

**请求体示例：**

```json
{
    "title": "Spring Boot 实战",
    "author": "Craig Walls",
    "price": 79.0,
    "stock": 10
}
```

> [!NOTE]
> `@RequestBody` 会使用 `HttpMessageConverter` 将请求体转换为 Java 对象。Spring Boot 默认使用 Jackson 处理 JSON。



### @RequestHeader —— 请求头

用于获取 HTTP 请求头中的值。

```java
@GetMapping("/books")
public List<Book> getBooks(@RequestHeader("User-Agent") String userAgent) {
    System.out.println("User-Agent: " + userAgent);
    return bookService.getAllBooks();
}
```



### 参数绑定总结

| 注解             | 数据来源       | 使用场景                     |
| ---------------- | -------------- | ---------------------------- |
| `@PathVariable`  | URL 路径       | 获取资源 ID（如 `/books/1`） |
| `@RequestParam`  | URL 查询字符串 | 过滤、搜索、分页参数         |
| `@RequestBody`   | HTTP 请求体    | 提交 JSON 数据（创建/更新）  |
| `@RequestHeader` | HTTP 请求头    | 认证 Token、客户端信息       |



## RESTful API 设计规范

### 资源命名

- 使用**复数名词**表示资源集合
- 使用小写字母和连字符

| 正确                      | 错误                        |
| ------------------------- | --------------------------- |
| `/api/books`              | `/api/getBooks`             |
| `/api/books/{id}`         | `/api/book/{id}`            |
| `/api/books/{id}/reviews` | `/api/bookReviews/{bookId}` |
| `/api/books/search`       | `/api/searchBooks`          |

### HTTP 方法与资源的映射

| 操作     | HTTP 方法 | URL               | 请求体   | 响应             |
| -------- | --------- | ----------------- | -------- | ---------------- |
| 获取列表 | GET       | `/api/books`      | 无       | 200 + 列表       |
| 获取单个 | GET       | `/api/books/{id}` | 无       | 200 + 对象 / 404 |
| 创建     | POST      | `/api/books`      | 对象     | 201 + 新对象     |
| 完整更新 | PUT       | `/api/books/{id}` | 对象     | 200 + 更新后对象 |
| 部分更新 | PATCH     | `/api/books/{id}` | 部分字段 | 200 + 更新后对象 |
| 删除     | DELETE    | `/api/books/{id}` | 无       | 204 / 404        |

### 状态码的使用

| 状态码                    | 使用场景                          |
| ------------------------- | --------------------------------- |
| 200 OK                    | GET、PUT、DELETE 成功             |
| 201 Created               | POST 创建成功（可选 Location 头） |
| 204 No Content            | DELETE 成功（无返回体）           |
| 400 Bad Request           | 请求参数错误                      |
| 404 Not Found             | 资源不存在                        |
| 500 Internal Server Error | 服务器内部错误                    |



## 实战：为图书管理系统编写完整接口

### 接口列表

| 方法   | URL                 | 功能           | 参数                                                   |
| ------ | ------------------- | -------------- | ------------------------------------------------------ |
| GET    | `/api/books`        | 查询所有图书   | 无                                                     |
| GET    | `/api/books/{id}`   | 查询单本图书   | 路径参数 `id`                                          |
| GET    | `/api/books/search` | 按条件查询     | 查询参数：`author`、`minPrice`、`maxPrice`、`category` |
| GET    | `/api/books/author` | 按作者查询     | 查询参数 `name`                                        |
| GET    | `/api/books/price`  | 按价格区间查询 | 查询参数 `min`、`max`                                  |
| POST   | `/api/books`        | 新增图书       | 请求体 `Book`                                          |
| PUT    | `/api/books/{id}`   | 更新图书       | 路径参数 `id` + 请求体 `Book`                          |
| DELETE | `/api/books/{id}`   | 删除图书       | 路径参数 `id`                                          |

### 完整 Controller 实现

```java
package com.example.bookmanager.controller;

import com.example.bookmanager.model.Book;
import com.example.bookmanager.service.BookService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/books")
public class BookController {

    @Autowired
    private BookService bookService;

    // 1. 查询所有图书
    @GetMapping
    public List<Book> getAllBooks() {
        return bookService.getAllBooks();
    }

    // 2. 查询单本图书（路径参数）
    @GetMapping("/{id}")
    public Book getBook(@PathVariable Long id) {
        return bookService.getBookById(id);
    }

    // 3. 按条件搜索（多查询参数，可空）
    @GetMapping("/search")
    public List<Book> searchBooks(
            @RequestParam(required = false) String author,
            @RequestParam(required = false) String category,
            @RequestParam(required = false) Double minPrice,
            @RequestParam(required = false) Double maxPrice) {
        return bookService.search(author, category, minPrice, maxPrice);
    }

    // 4. 按作者查询（查询参数）
    @GetMapping("/author")
    public List<Book> getBooksByAuthor(@RequestParam String name) {
        return bookService.getBooksByAuthor(name);
    }

    // 5. 按价格区间查询
    @GetMapping("/price")
    public List<Book> getBooksByPriceRange(
            @RequestParam Double min,
            @RequestParam Double max) {
        return bookService.getBooksByPriceRange(min, max);
    }

    // 6. 新增图书（请求体）
    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public Book createBook(@RequestBody Book book) {
        return bookService.createBook(book);
    }

    // 7. 更新图书（路径参数 + 请求体）
    @PutMapping("/{id}")
    public Book updateBook(
            @PathVariable Long id,
            @RequestBody Book book) {
        book.setId(id);
        return bookService.updateBook(book);
    }

    // 8. 删除图书（路径参数）
    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    public void deleteBook(@PathVariable Long id) {
        bookService.deleteBook(id);
    }
}
```



### 注意事项

#### 1. @RequestBody 与 @RequestParam 的区别

| 对比     | @RequestBody     | @RequestParam             |
| -------- | ---------------- | ------------------------- |
| 数据来源 | 请求体           | URL 查询字符串            |
| 数据格式 | JSON/XML         | key=value                 |
| 适用方法 | POST、PUT、PATCH | GET（也可用于 POST 表单） |
| 对象绑定 | 支持复杂对象     | 仅支持基本类型            |

#### 2. 参数绑定失败的处理

当 `@RequestParam` 设为 `required=true` 且缺失时，Spring 会抛出 `MissingServletRequestParameterException`，可通过全局异常处理统一响应。

#### 3. 路径变量类型转换

Spring 自动将路径变量转换为方法参数类型。如果转换失败，会抛出 `MethodArgumentTypeMismatchException`。

```java
@GetMapping("/books/{id}")
public Book getBook(@PathVariable Long id) { ... }
// 请求 /books/abc 时，'abc' 无法转换为 Long，抛出异常
```

#### 4. 请求体过大

默认限制为 2MB，可通过配置调整：

```yaml
spring:
  servlet:
    multipart:
      max-request-size: 10MB
```



## 参数校验

### 参数校验的重要性

在 Web 开发中，客户端提交的数据往往不可靠，必须经过校验才能使用。如果没有校验，可能导致：

- 空指针异常（如 name 为 null）
- 数据库错误（如年龄超出范围）
- 安全漏洞（如注入攻击）

**校验的层次：**

1. 客户端校验（前端表单校验）—— 用户体验
2. 服务端校验（后端参数校验）—— **必须执行，保证数据安全**

> [!NOTE]
> 客户端校验可以被绕过，**服务端校验是最后一道防线**，必须严格执行。



### Bean Validation 简介

**Bean Validation** 是 Java 的一个标准规范（JSR 303/380），通过注解的方式对 Java Bean 的属性进行校验。Spring Boot 集成了 Hibernate Validator（Bean Validation 的参考实现），无需额外配置即可使用。

Spring Boot 的 `spring-boot-starter-web` 已经包含了 `spring-boot-starter-validation`，无需额外添加。如果项目中未包含，可以手动添加：

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>
```

> [!NOTE]
> 在 Spring Boot 2.3+ 中，`spring-boot-starter-web` 不再默认包含 `validation`，需要显式添加。确保 `pom.xml` 中有此依赖。



### 常用校验注解

#### 内置校验注解

| 注解              | 说明                              | 示例                                  |
| ----------------- | --------------------------------- | ------------------------------------- |
| `@NotNull`        | 字段不能为 null                   | `@NotNull`                            |
| `@NotBlank`       | 字符串不能为空（trim 后长度 > 0） | `@NotBlank(message = "书名不能为空")` |
| `@NotEmpty`       | 集合/字符串不能为空（长度 > 0）   | `@NotEmpty`                           |
| `@Size`           | 字符串/集合大小在指定范围内       | `@Size(min = 1, max = 100)`           |
| `@Min`            | 数字最小值                        | `@Min(0)`                             |
| `@Max`            | 数字最大值                        | `@Max(150)`                           |
| `@DecimalMin`     | 小数最小值                        | `@DecimalMin("0.00")`                 |
| `@DecimalMax`     | 小数最大值                        | `@DecimalMax("9999.99")`              |
| `@Pattern`        | 正则表达式匹配                    | `@Pattern(regexp = "^[A-Z].*$")`      |
| `@Email`          | 邮箱格式                          | `@Email`                              |
| `@Past`           | 日期必须为过去                    | `@Past`                               |
| `@Future`         | 日期必须为未来                    | `@Future`                             |
| `@Positive`       | 正数（大于0）                     | `@Positive`                           |
| `@PositiveOrZero` | 正数或零                          | `@PositiveOrZero`                     |
| `@Negative`       | 负数                              | `@Negative`                           |
| `@NegativeOrZero` | 负数或零                          | `@NegativeOrZero`                     |

#### 在实体类中添加校验注解

```java
package com.example.bookmanager.model;

import javax.validation.constraints.*;

public class Book {

    private Long id;

    @NotBlank(message = "书名不能为空")
    @Size(min = 1, max = 100, message = "书名长度必须在1-100之间")
    private String title;

    @NotBlank(message = "作者不能为空")
    @Size(max = 50, message = "作者名不能超过50个字符")
    private String author;

    @NotNull(message = "价格不能为空")
    @DecimalMin(value = "0.00", message = "价格不能为负数")
    @DecimalMax(value = "9999.99", message = "价格不能超过9999.99")
    private Double price;

    @NotNull(message = "库存不能为空")
    @Min(value = 0, message = "库存不能为负数")
    private Integer stock;

  // Getter 和 Setter...
}
```

#### 自定义校验消息

消息可以从配置文件中读取，也可以直接在注解中写死。

**方式一：直接在注解中指定**

```java
@NotBlank(message = "书名不能为空")
```

**方式二：从 ValidationMessages.properties 读取（国际化）**
创建 `src/main/resources/ValidationMessages.properties`：

```properties
book.title.notnull=书名不能为空
book.title.size=书名长度必须在1-100之间
book.price.min=价格不能为负数
```

使用：

```java
@NotBlank(message = "{book.title.notnull}")
@Size(min = 1, max = 100, message = "{book.title.size}")
```



### 触发校验

#### @Valid 注解

在 Controller 的方法参数上添加 `@Valid` 注解，触发校验。

```java
@PostMapping
@ResponseStatus(HttpStatus.CREATED)
public Book createBook(@Valid @RequestBody Book book) {
    return bookService.createBook(book);
}

@PutMapping("/{id}")
public Book updateBook(
        @PathVariable Long id,
        @Valid @RequestBody Book book) {
    book.setId(id);
    return bookService.updateBook(book);
}
```

#### 校验结果处理

默认情况下，校验失败会抛出 `MethodArgumentNotValidException`。可以通过全局异常处理统一捕获。我们将在下一讲中介绍全局异常处理统一捕获机制。

### 引入Lombok

**Lombok是一个Java库，它能通过注解自动生成样板代码**，从而帮助开发者摆脱编写getter、setter、构造方法等重复性劳动，让代码更加简洁

#### 安装和配置Lombok

| 方面         | 描述                                                         |
| ------------ | ------------------------------------------------------------ |
| **核心目标** | 消除Java代码中的样板代码（boilerplate code），提高开发效率。 |
| **实现方式** | 提供一系列注解，在**编译时**自动生成对应的字节码，注入到`.class`文件中。 |
| **主要用途** | 简化POJO（Plain Old Java Object）、Java Bean、实体类等的创建。 |
| **工作方式** | 非运行时反射，而是通过**编译时注解处理（APT）** 技术，在代码编译阶段“插入”处理逻辑。 |

为了让 IDEA 能识别并支持 Lombok 的注解（如提供代码提示），需要先安装插件。

1. **打开设置**：点击菜单栏 `File` -> `Settings` (Windows/Linux) 或 `IntelliJ IDEA` -> `Preferences` (macOS)。也可以直接使用快捷键 `Ctrl+Alt+S`。
2. **搜索插件**：在设置窗口左侧选择 `Plugins`，然后切换到顶部的 `Marketplace` 标签页。
3. **安装插件**：在搜索框输入 `Lombok`，找到插件（图标是一个红色辣椒或咖啡杯），点击 `Install` 安装。
4. **重启 IDEA**：安装完成后，根据提示重启 IDEA 使插件生效。

Lombok 需要在项目的构建文件中声明为依赖，才能在编译时生效：

```xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <version>1.18.30</version> 
    <scope>provided</scope>
    <optional>true</optional>
</dependency>
```

#### Lombok注解

配置完成后，就可以在代码中使用注解来简化开发了。以下是几个最常用的注解：

| 注解                      | 作用                                                         | 示例                                               |
| ------------------------- | ------------------------------------------------------------ | -------------------------------------------------- |
| **`@Data`**               | 最常用的注解，组合了 `@Getter`、`@Setter`、`@ToString`、`@EqualsAndHashCode` 和 `@RequiredArgsConstructor` 的功能。 | `@Data public class User { ... }`                  |
| **`@Getter` / `@Setter`** | 为字段生成 getter 和 setter 方法。可作用在类或字段上。       | `@Getter @Setter private String name;`             |
| **`@NoArgsConstructor`**  | 生成一个无参构造函数。                                       | `@NoArgsConstructor public class Order { ... }`    |
| **`@AllArgsConstructor`** | 生成一个包含所有字段的构造函数。                             | `@AllArgsConstructor public class Item { ... }`    |
| **`@Builder`**            | 提供构建者模式，用于优雅地创建对象。                         | `User user = User.builder().name("test").build();` |
| **`@ToString`**           | 生成 `toString` 方法，可用 `exclude` 属性排除字段。          | `@ToString(exclude = {"password"})`                |
| **`@EqualsAndHashCode`**  | 生成 `equals` 和 `hashCode` 方法。                           | `@EqualsAndHashCode(of = {"id", "name"})`          |

### Controller 添加校验

```java
@RestController
@RequestMapping("/api/books")
public class BookController {

    @PostMapping
    @ResponseStatus(HttpStatus.CREATED)
    public Book createBook(@Valid @RequestBody Book book) {
        return bookService.createBook(book);
    }

    @PutMapping("/{id}")
    public Book updateBook(
            @PathVariable Long id,
            @Valid @RequestBody Book book) {
        book.setId(id);
        return bookService.updateBook(book);
    }

    // 查询接口也需要校验路径参数（如ID必须是正数）
    @GetMapping("/{id}")
    public Book getBook(@Min(1) @PathVariable Long id) {
        return bookService.getBookById(id);
    }

    @GetMapping("/price")
    public List<Book> getBooksByPriceRange(
            @DecimalMin("0.00") @RequestParam Double min,
            @DecimalMax("9999.99") @RequestParam Double max) {
        return bookService.getBooksByPriceRange(min, max);
    }
}
```



## 小结

本节课我们学习了：

1. **请求映射注解**：
   - `@RequestMapping` 及组合注解（@GetMapping、@PostMapping 等）
   - 路径匹配规则（精确匹配、路径参数、通配符）
2. **参数绑定注解**：
   - `@PathVariable`：提取 URL 路径变量
   - `@RequestParam`：提取查询参数
