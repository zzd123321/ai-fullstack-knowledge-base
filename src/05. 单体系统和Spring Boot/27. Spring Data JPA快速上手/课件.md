本节课我们将通过图书管理系统，一步步实现从 Spring JDBC 到 Spring Data JPA 的迁移，并使用 PostgreSQL 作为生产级数据库。

### 添加 Spring Data JPA 和 PostgreSQL 依赖

在 `pom.xml` 中添加以下依赖：

```xml
<!-- Spring Data JPA -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>

<!-- PostgreSQL 驱动 -->
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
    <scope>runtime</scope>
</dependency>
```

> [!NOTE]
> `spring-boot-starter-data-jpa` 会自动引入 Hibernate（JPA 实现）、Spring Data JPA 以及 `spring-tx`（事务支持）。PostgreSQL 驱动由 Spring Boot 自动管理版本，无需指定。

### 数据源与 JPA 配置

在 `application.yml` 中配置 PostgreSQL 数据源和 JPA 属性：

```yaml
spring:
  datasource:
    driver-class-name: org.postgresql.Driver
    url: jdbc:postgresql://localhost:5432/bookdb
    username: postgres
    password: your_password

  jpa:
    # 控制台显示 SQL
    show-sql: true
    # 自动建表策略
    hibernate:
      ddl-auto: update
    # 数据库方言
    properties:
      hibernate:
        dialect: org.hibernate.dialect.PostgreSQLDialect
        format_sql: true
        use_sql_comments: true
        jdbc:
          lob:
            non_contextual_creation: true
```

**配置参数说明：**

| 参数                                | 说明                                               |
| ----------------------------------- | -------------------------------------------------- |
| `show-sql: true`                    | 在控制台打印 SQL 语句（开发时方便调试）            |
| `ddl-auto: update`                  | 根据实体自动更新表结构（开发环境）                 |
| `dialect`                           | 指定 PostgreSQL 方言，Hibernate 据此生成正确的 SQL |
| `format_sql: true`                  | 格式化 SQL 语句，增强可读性                        |
| `lob.non_contextual_creation: true` | 解决 PostgreSQL 中大对象创建问题                   |

> [!CAUTION]
> `ddl-auto: update` 仅适用于开发环境，会**自动修改表结构**，有数据丢失风险。生产环境应设置为 `none` 或使用迁移工具（如 Flyway、Liquibase）。



## 定义 JPA 实体

### 实体映射注解

| 注解              | 作用                                |
| ----------------- | ----------------------------------- |
| `@Entity`         | 标记该类为 JPA 实体，映射到数据库表 |
| `@Table`          | 指定映射的表名（默认与类名相同）    |
| `@Id`             | 标记主键字段                        |
| `@GeneratedValue` | 主键生成策略                        |
| `@Column`         | 指定列名、长度、是否可空等          |
| `@Transient`      | 标记非持久化字段                    |
| `@Enumerated`     | 映射枚举类型                        |
| `@Lob`            | 映射大对象（CLOB、BLOB）            |

### 图书实体完整定义

在 `com.example.bookmanager.model` 包下创建 `Book.java`：

```java
@Entity
@Table(name = "book")
@Data
@NoArgsConstructor
public class Book {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 200)
    private String title;

    @Column(nullable = false, length = 100)
    private String author;

    @Column(nullable = false)
    private Double price;

    @Column(nullable = false)
    private Integer stock;

    private Integer sales;  // 允许为 null，默认为 0 可在业务层处理

    @Column(length = 50)
    private String category;

    @CreationTimestamp
    @Column(updatable = false)
    private LocalDateTime createdAt;

    @UpdateTimestamp
    private LocalDateTime updatedAt;

    // 可添加业务构造器，便于创建实例
    public Book(String title, String author, Double price, Integer stock, String category) {
        this.title = title;
        this.author = author;
        this.price = price;
        this.stock = stock;
        this.category = category;
        this.sales = 0; // 默认销量为0
    }
}
```

### 主键生成策略

| 策略                      | 说明             | PostgreSQL 对应        |
| ------------------------- | ---------------- | ---------------------- |
| `GenerationType.IDENTITY` | 使用数据库自增列 | `bigserial` / `serial` |
| `GenerationType.SEQUENCE` | 使用数据库序列   | `SEQUENCE`（推荐）     |
| `GenerationType.TABLE`    | 使用单独的序列表 | 兼容但性能较差         |
| `GenerationType.AUTO`     | 自动选择（默认） | 默认为 `SEQUENCE`      |

> [!NOTE]
> 对于 PostgreSQL，推荐使用 `SEQUENCE` 以获得更好的性能和灵活性，但 `IDENTITY` 更简单。本课使用 `IDENTITY` 以便快速上手。



## 定义 Repository 接口

### 基础 Repository

在 `com.example.bookmanager.repository` 包下创建 `BookRepository.java`：

```java
package com.example.bookmanager.repository;

import com.example.bookmanager.model.Book;
import org.springframework.data.jpa.repository.JpaRepository;
import org.springframework.stereotype.Repository;

@Repository
public interface BookRepository extends JpaRepository<Book, Long> {
    // 无需任何方法，JpaRepository 已提供完整的 CRUD 功能
}
```

> [!NOTE]
> `JpaRepository<Book, Long>` 中的两个类型参数分别是：实体类型和主键类型。

### 自动获得的方法

通过继承 `JpaRepository`，`BookRepository` 自动获得了以下方法（无需实现）：

| 方法                               | 说明                                  |
| ---------------------------------- | ------------------------------------- |
| `save(Book entity)`                | 保存实体（插入或更新）                |
| `saveAll(Iterable<Book> entities)` | 批量保存                              |
| `findById(Long id)`                | 根据 ID 查询（返回 `Optional<Book>`） |
| `findAll()`                        | 查询全部                              |
| `findAllById(Iterable<Long> ids)`  | 根据 ID 列表查询                      |
| `findAll(Pageable pageable)`       | 分页查询                              |
| `findAll(Sort sort)`               | 排序查询                              |
| `count()`                          | 统计总数                              |
| `existsById(Long id)`              | 判断是否存在                          |
| `deleteById(Long id)`              | 根据 ID 删除                          |
| `delete(Book entity)`              | 删除实体                              |
| `deleteAll()`                      | 删除全部                              |

## 使用 Repository 完成 CRUD

### Service 层注入 Repository

```java
package com.example.bookmanager.service;

@Service
public class BookServiceImpl implements BookService {

    private final BookRepository bookRepository;

    public BookServiceImpl(BookRepository bookRepository) {
        this.bookRepository = bookRepository;
    }
  
    @Override
    @Transactional(rollbackFor = BusinessException.class)
    public Book createBook(Book book) {
        // 业务校验：价格不能为负数
        if (book.getPrice() == null || book.getPrice() < 0) {
            throw new BusinessException("图书价格不能为空或为负数");
        }
        // 业务校验：库存不能为负数
        if (book.getStock() == null || book.getStock() < 0) {
            throw new BusinessException("库存不能为负数");
        }

        System.out.println("添加Book：" + book.getTitle());
        return bookRepository.save(book);
    }

    @Override
    @Transactional(rollbackFor = BusinessException.class)
    public Book updateBook(Book book) {
        if (book.getId() == null) {
            throw new IllegalArgumentException("更新图书时 ID 不能为空");
        }
        // 使用 Optional 正确判断记录是否存在
        Book existing = bookRepository.findById(book.getId())
                .orElseThrow(() -> new ResourceNotFoundException("要更新的图书不存在，ID: " + book.getId()));
        // 可在此处进行字段合并等操作，此处直接保存（会覆盖所有字段）
        return bookRepository.save(book);
    }

    @Override
    @Transactional(rollbackFor = BusinessException.class)
    public boolean deleteBook(Long id) {
        if (id == null) {
            throw new IllegalArgumentException("删除时 ID 不能为空");
        }
        bookRepository.deleteById(id);
        return true;
    }

    @Override
    @Transactional(readOnly = true)
    public Book getBookById(Long id) {
        return bookRepository.findById(id)
                .orElseThrow(() -> new ResourceNotFoundException("Book", id));
    }

    @Override
    @Transactional(readOnly = true)
    public List<Book> getAllBooks() {
        return bookRepository.findAll();
    }
}
```

## Entity 的生命周期回调

JPA 提供了多个生命周期回调注解，用于在实体状态变化时自动执行特定方法：

| 注解           | 触发时机                               |
| -------------- | -------------------------------------- |
| `@PrePersist`  | 实体被持久化之前（调用 `save` 插入前） |
| `@PostPersist` | 实体被持久化之后                       |
| `@PreUpdate`   | 实体被更新之前                         |
| `@PostUpdate`  | 实体被更新之后                         |
| `@PreRemove`   | 实体被删除之前                         |
| `@PostRemove`  | 实体被删除之后                         |
| `@PostLoad`    | 实体被加载之后（查询后）               |

```java
@Entity
public class Book {
    @PrePersist
    protected void onCreate() {
        createdAt = LocalDateTime.now();
        updatedAt = LocalDateTime.now();
    }

    @PreUpdate
    protected void onUpdate() {
        updatedAt = LocalDateTime.now();
    }
}
```



## Spring Data JPA vs JdbcTemplate 对比

| 操作     | JdbcTemplate         | Spring Data JPA                    |
| -------- | -------------------- | ---------------------------------- |
| 查询全部 | 手写 SQL + RowMapper | `findAll()`                        |
| 查询单条 | 手写 SQL + RowMapper | `findById(id)`                     |
| 插入     | 手写 SQL + KeyHolder | `save(entity)`                     |
| 更新     | 手写 SQL             | `save(entity)`（根据 ID 自动判断） |
| 删除     | 手写 SQL             | `deleteById(id)`                   |
| 统计     | 手写 SQL             | `count()`                          |

**Spring Data JPA 的优势：**

- 无需编写 SQL 语句
- 无需编写结果集映射
- 无需手动管理主键生成
- 代码量减少 70% 以上

**适用场景：**

- 标准 CRUD 操作
- 业务逻辑复杂的领域模型
- 需要快速开发的场景

**JdbcTemplate 仍然适用的场景：**

- 需要手写复杂 SQL（多表关联、聚合查询）
- 对 SQL 性能有极致要求
- 需要精细控制 SQL 执行过程



## 注意事项

### 1. 实体类必须有无参构造方法

JPA 通过反射创建实体实例，必须提供**无参构造方法**（可以是 `private`）。

```java
public Book() { }  // JPA 要求
```

### 2. PostgreSQL 自增主键

使用 `GenerationType.IDENTITY` 时，PostgreSQL 对应 `bigserial` 类型，Hibernate 会自动创建序列。

### 3. 注意 equals 和 hashCode

建议重写 `equals` 和 `hashCode`，使用业务唯一标识（如 `id` 或业务主键），避免在集合操作时出现意外行为。

### 4. 避免在实体中使用基本类型

```java
// ❌ 不推荐：基本类型无法表示 null
private int stock;

// ✅ 推荐：使用包装类
private Integer stock;
```



## 小结

本节课我们学习了：

1. **Spring Data JPA 的依赖与配置**：
   - `spring-boot-starter-data-jpa` 依赖
   - PostgreSQL 驱动和连接配置
   - JPA 属性（`ddl-auto`、`show-sql`、`dialect` 等）
2. **JPA 实体映射**：
   - `@Entity`、`@Table`、`@Id`、`@GeneratedValue`、`@Column`
   - `@PrePersist`、`@PreUpdate` 生命周期回调
3. **Repository 接口**：
   - 继承 `JpaRepository<T, ID>` 自动获得完整 CRUD 方法
   - 无需编写实现类
4. **CRUD 操作**：`save`、`findById`、`findAll`、`deleteById`、`count` 等
5. **Service 层注入**：在 Service 中注入 Repository 并调用
6. **对比 JdbcTemplate**：Spring Data JPA 代码量大幅减少，适合标准 CRUD 场景
