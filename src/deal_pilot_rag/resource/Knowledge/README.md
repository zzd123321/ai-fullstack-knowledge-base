# Knowledge

从 [知识索引](wiki/index.md) 开始浏览。

这是一轮基于 `resource/企业知识库` 全部资料编排的 LLM Wiki 实操产物：18 份文档、9 张图片，生成 27 个来源页、10 个实体页、7 个跨文档主题页，以及总索引。可以直接用 Markdown 阅读器打开，也可以将本目录作为 Obsidian 库浏览相对链接。

```text
Knowledge/
├── raw/                 # 27 份原始文件的完整副本，保留目录结构
├── wiki/
│   ├── index.md         # 问题导航与完整页面目录
│   ├── entities/        # 客户、产品、组件、模型与角色
│   ├── concepts/        # 跨文档整合的主题知识
│   └── sources/         # 一份原始资料对应一个摘要／图片提取页
├── schema.md            # 格式、来源与后续摄入／查询／检查规则
├── log.md               # 本轮处理和校验记录
├── manifest.json        # 原始路径、SHA-256、来源页及关联知识页
└── AGENTS.md            # 本目录维护入口与约束
```

先看 [华辰精工](wiki/entities/华辰精工.md)，再看 [价格版本与折扣审批](wiki/concepts/价格版本与折扣审批.md) 和 [引擎升级风险与项目影响](wiki/concepts/引擎升级风险与项目影响.md)，可以看到同一份资料如何同时进入多个知识页面。

**时间范围：**资料快照截至 2026-08-20，整理日期为 2026-11-04。没有将过期的计划、待批申请或尚未验证条件改成完成状态。完整边界见 [版本演进与待确认事项](wiki/concepts/版本演进与待确认事项.md)。

**实现状态：**本轮已完成静态资料整理、直接视觉读图及本地链接／完整性检查。维护流程写在 schema 中，后续可由 Agent 按规则执行；没有安装后台自动更新器、连接生产系统、生成向量索引或进行客户现场验证。原始资料与工程业务代码未修改。
