# A400推理一体机

四卡配置与 70B Q4 能力边界，避免将试点扩展为 FP16 保证。

> 资料快照：2026-08-20；整理日期：2026-11-04。状态与结论仅适用于所引证据的时间、版本和范围。

## 标准配置与价格

CFG-A400-4：4×AX48，每卡 48 GB；1 TB 内存、2 TB 系统盘＋16 TB 数据盘、双口 25 GbE、4U，出厂引擎 3.2.0。标准包含推理引擎、基础知识库应用、S30 和三年维保。八月含税设备目录价 698000 元；L23、专项集成、延保另报。[PROD-002 · A400 推理一体机产品与配置说明](../sources/PROD-002.md) [BIZ-002 · 推理一体机八月价格与折扣政策](../sources/BIZ-002.md)

## 已有证据

星语 70B v1 Q4、引擎 3.2.0、输出 256 tokens 的四组模型基准见 [TEST-002 · A400 星语 70B 性能测试报告](../sources/TEST-002.md)；4096 输入／四请求时合计 148 tokens/s、首 token P95 1.9 秒。衡远相应试点应用 P95 为 3.8 秒，属于不同计时范围。[SOL-003 · 衡远设计资料助手试点案例](../sources/SOL-003.md)

S30 2.0＋工务通 3.0 的读取组合已有实验室记录；L23 1.0＋工务通 2.3 未验证。没有 70B FP16 或 16000 输入／八请求的性能证据。[PROD-003 · 推理引擎和业务连接器兼容清单](../sources/PROD-003.md) [TEST-003 · 工务通文档读取接口兼容验证](../sources/TEST-003.md) [TEST-002 · A400 星语 70B 性能测试报告](../sources/TEST-002.md)
