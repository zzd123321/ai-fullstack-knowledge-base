# 课程导读

## 1. 项目介绍

使用 langgraph 实现 AI 漫剧



## 2.课程目标

这是一门**<u>选修课</u>**，主要目的在于**<u>练习使用langgraph</u>**

**适合哪些同学？**

- 学习时间充足
- 理解能力弱
- 想要：学习使用火山引擎（简单）
- 想要：学习文生图、视频（简单）
- 不涉及：用户隔离、资源隔离、安全、权限、观测评估....



## 3. 课程特点

**从零到一带同学跑通核心流程，夯实 Python 与 LangGraph 实战能力。**



**特点1：涵盖 LangGraph 核心能力**

这门课会包含：

1. 状态图（StateGraph）
2. Reducer
3. 固定并行：扇出 + 汇合
4. Send：运行时动态并行
5. 子图
6. interrupt
7. Command
8. Checkpointer
9. Thread
10. 自定义流（custom stream）
11. ....



**特点2：从 0 到 1 完成项目**

1. 从新建文件夹开始
2. 课件包含详细步骤
3. 半古法编程
4. 详细的资料
   1. 文档
   2. 示意图、脑图
   3. 代码仓库持续演进，但每节课代码独立



**特点3：精简**

1. 需求为导向
2. 每节课控制在 30 分钟以内
