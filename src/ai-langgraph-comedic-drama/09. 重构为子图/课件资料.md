**2. 将原来的图变成一张子图**

在 `workflows` 下新建 `story_planning.py` ，然后将之前 `graph.py` 里面的所有内容原封不动的放入  `story_planning.py`



**3. 创建 graph.py**

重新创建 `graph.py`，代码如下：

```py
from langgraph.graph import END, START, StateGraph

from server.model import TextModel, build_text_model
from server.states import ComicDramaState
from server.workflows.story_planning import build_story_planning_graph


def build_graph(text_model: TextModel):
    planning_graph = build_story_planning_graph(text_model)

    def story_planning(state: ComicDramaState) -> dict[str, object]:
        child_result = planning_graph.invoke(state)
        # 子图返回完整事件历史；父图 reducer 只追加本轮新事件。
        return {
            **child_result,
            "events": child_result["events"][len(state["events"]) :],
        }

    builder = StateGraph(ComicDramaState)

    # 添加节点
    builder.add_node("story_planning", story_planning)

    # 连边
    builder.add_edge(START, "story_planning")
    builder.add_edge("story_planning", END)

    return builder.compile()


graph = build_graph(build_text_model())
```



**注意点1**

`graph.py` 中引入 `build_story_planning_graph` 方法时，**<u>必须要写绝对路径</u>**，如下：

`from server.workflows.story_planning import build_story_planning_graph`

不能写相对路径：`from .story_planning import build_story_planning_graph`

原因：

LangGraph 会把 `graph.py` 当独立脚本执行，这时它没有父包（`__package__` 为空）。

`.` 表示“当前包”，**<u>没有父包就不能用相对导入</u>**，于是会报错：

```
ImportError: attempted relative import with no known parent package
```





**注意点2**

```py
return {
    **child_result,
    "events": child_result["events"][len(state["events"]) :],
}
```

这两行是在把**<u>子图的完整结果交回父图</u>**，`planning_graph.invoke(state)` 跑完子图后，`child_result` 是**整份最终 State**，里面既有旧字段，也有本轮新写的字段。父图节点必须返回一份 **更新 dict**，不是整份状态对象。



**`**child_result`**

把**<u>子图结果拆开，原样写进返回值</u>**。`requirement`、`story_outline`、`characters`、`current_stage` 这些字段在父图里是**<u>覆盖</u>**写入，所以整份带回去没问题。



**`"events": child_result["events"][len(state["events"]) :]`**

`events` 不一样。它在 State 里声明了 `operator.add`：

```python
    events: Annotated[list[str], operator.add]
```

如果原样交回去：

- 进入子图前：`["已接收用户创意"]`
- 子图结束后：`["已接收用户创意", "已生成结构化创意需求", "已生成故事大纲", ...]`
- 父图再 `add` 一次：历史会出现两遍
  - `["已接收用户创意", "已接收用户创意", "已生成结构化创意需求", "已生成故事大纲", ...]`

所以这里只切出**本轮新增**的那一段：从进入子图时的长度切到末尾。上面的例子里，`len(state["events"])` 是 1，切片结果是：

```python
["已生成结构化创意需求", "已生成故事大纲"]
```

父图再 `add`，历史就只追加一次。

后面的 `"events"` 会覆盖前面 `**child_result` 里的同名字段，所以顺序必须是：先展开全部，再单独改 `events`。
